# HORDA · Press kit

**3 vs 3 vs la Horda.** Una ciudad muerta. Tres cajas para escapar.

Press kit oficial de **HORDA**, un shooter táctico de extracción en el que se enfrentan 3 contra 3 contra la Horda.

🌐 **Sitio en vivo:** https://joseortizz1807.github.io/horda-presskit/

## Contenido
| Carpeta | Qué hay |
|---|---|
| `index.html` | La página del press kit (ficha, tráiler, capturas, héroes, mecánicas, presentación, logos, equipo) |
| `video/` | Tráiler 1080p para web (`HORDA_trailer.mp4`), versión vertical 9:16 para Reels/TikTok y póster |
| `img/screens/` | 13 capturas del juego en alta, con miniaturas |
| `img/heroes/` | Retratos de los 10 héroes |
| `img/deck/` | Las 17 diapositivas de la presentación |
| `download/` | `HORDA_presskit.zip` (logos, capturas, héroes, ficha) y `HORDA_presentacion.pdf` |

## Activar el link de itch.io y YouTube
Al final de `index.html` hay dos líneas:
```js
const ITCH_URL = "";     // tu página de itch.io
const YOUTUBE_ID = "";   // el código del video de YouTube (lo que va después de watch?v=)
```
Llénalas y guarda: el botón de itch.io se activa solo y, si pones el ID de YouTube, el tráiler se reproduce desde YouTube.
